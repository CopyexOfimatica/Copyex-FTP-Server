COPYEX FTP SERVER - CAMBIOS RESPECTO A 2.1.1
============================================

INTERFAZ
- Diseño nuevo con el rojo corporativo Copyex: barra lateral (Panel, Usuarios,
  Configuración, Registro), tarjetas e iconos de Windows. Logo Copyex visible arriba a la
  derecha en todas las páginas. Icono de la aplicación en rojo.
- Botones claros: Iniciar (verde ▶), Detener (rojo ■), Reiniciar (naranja ⟳).
- Cambio rápido del puerto FTP desde el Panel (reinicia el servidor si está en marcha).
- Botón «Acceso directo» para crear/actualizar ESCANER en el escritorio.
- Registro con filtro y «seguir al final»; solo en memoria (se borra al cerrar).
- Notificaciones agrupadas; al pulsarlas se abre la carpeta con el archivo seleccionado.
- Abrir el EXE cuando ya está en la bandeja muestra la ventana existente.

NUEVO: SFTP OPCIONAL
- Desactivado por defecto. Se activa en Configuración > SFTP (puerto 22 por defecto).
- Mismos usuarios, contraseñas, carpetas y permisos que el FTP.
- Algoritmos modernos (ECDH P-256, AES-CTR, HMAC-SHA2) y, como último recurso para
  escáneres antiguos, DH group14-sha1 / ssh-rsa / hmac-sha1.
- Solo transferencia de archivos: sin consola ni ejecución de comandos.
- Clave del servidor RSA-3072 guardada junto a config.json (sftp_host_key.pem); su huella
  se muestra en Configuración.

SEGURIDAD
- Robo de conexión pasiva: el puerto de datos solo acepta la IP del cliente.
- Límite de conexiones total y por IP; cierre de sesiones inactivas.
- Contraseña errónea: 1 s de espera y corte de esa conexión tras 3 fallos
  (sin bloqueo de IP: el escáner puede volver a conectar en el acto).
- Líneas de comando limitadas a 4 KB (antes: memoria ilimitada).
- Rutas: se rechazan flujos NTFS (a.pdf:x), letras de unidad, nombres de dispositivo
  (CON, NUL…), comodines y caracteres de control. Nunca se sale de la raíz.
- No se puede borrar ni renombrar la carpeta raíz.
- Modo activo solo hacia la IP del cliente y puertos >= 1024 (anti FTP bounce).
- Solo red local por defecto.
- No se permite usar como raíz C:\, Windows, Archivos de programa ni el perfil completo.
- Contraseñas nuevas con 210.000 iteraciones PBKDF2 (las de 2.x siguen funcionando).
- PowerShell por ruta absoluta y script codificado.
- Cambiar o deshabilitar un usuario cierra al momento sus sesiones abiertas.

FALLOS CORREGIDOS
- REST + STOR (reanudar subidas) corrompía el archivo.
- LIST usaba meses en español («oct.») que algunos clientes no entienden.
- Los cambios de usuarios no se aplicaban hasta reiniciar el servidor.
- La aplicación impedía el apagado de Windows.
- config.json podía corromperse al guardar; si está dañado se aparta una copia.
- Fijar IP: si Windows la rechazaba el adaptador quedaba sin IP; ahora se restaura.
- Acceso directo con API nativa (funciona aunque Windows Script Host esté bloqueado).
- Reinicio de la aplicación fiable.

RECURSOS
- Registro en memoria con tamaño fijo (sin escritura en disco).
- La ventana solo lee el registro cuando está visible.
- Consulta de red asíncrona (la ventana no se congela al arrancar).
- Búsqueda de IPs libres en segundos (pings en paralelo + tabla ARP).
- Transferencias con vigilancia de bloqueo y búferes reutilizados.
